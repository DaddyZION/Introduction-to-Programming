# COMP101 Introduction to Programming - Learning Project

Welcome to your comprehensive learning project for COMP101! This repository is designed to teach you fundamental programming concepts through practical examples and exercises.

## 📚 Course Overview

This course uses **100% coursework assessment** with 7 individual assignments covering core programming concepts:

| Assignment | Weight | Topic | Focus |
|------------|--------|-------|-------|
| Assignment 1 | 12% | Sequence Constructs | Variables, input/output, basic operations |
| Assignment 2 | 12% | Selection Constructs | if/else statements, conditional logic |
| Assignment 3 | 13% | Iteration Constructs | Loops (for, while, do-while) |
| Assignment 4 | 13% | Validation Control | Input validation, error handling |
| Assignment 5 | 16% | Functions | Modularization, parameters, return values |
| Assignment 6 | 16% | 1D Arrays & Strings | Array manipulation, string processing |
| Assignment 7 | 18% | 2D Arrays & Numerics | Matrix operations, numeric computations |

## 🎯 Learning Approach

Each folder contains:
- **Concept explanations** with detailed comments
- **Progressive examples** from basic to advanced
- **Practice exercises** with solutions
- **Common mistakes** and how to avoid them
- **Real-world applications** of each concept

## 🚀 Getting Started

1. **Start with Assignment 1** - Build your foundation with sequence constructs
2. **Work through each assignment in order** - Each builds on previous concepts
3. **Read all comments carefully** - They explain the "why" not just the "what"
4. **Try the exercises** - Practice is essential for programming
5. **Experiment with the code** - Modify examples to see what happens

## 💡 Study Tips

- **Make a reasonable attempt on all assignments** - Non-submission = 0%
- **Understand, don't memorize** - Focus on concepts over syntax
- **Practice regularly** - Programming is a skill that improves with practice
- **Ask questions** - If something isn't clear, seek clarification
- **Test your code** - Always verify your programs work correctly
