# Assignment 5 - Functions and Modular Programming

This assignment covers function definition, parameters, return values, scope, and modular programming concepts essential for writing organized, reusable code.

## Learning Objectives

By completing this assignment, you will understand:

1. **Function Basics**
   - Function definition and syntax
   - Function calls and execution
   - Return values and None
   - Function documentation

2. **Parameters and Arguments**
   - Required parameters
   - Default parameter values
   - Variable-length arguments (*args, **kwargs)
   - Parameter passing mechanisms

3. **Scope and Variables**
   - Local vs global scope
   - Variable lifetime
   - Global and nonlocal keywords
   - Scope resolution rules

4. **Advanced Function Concepts**
   - Nested functions
   - Lambda functions
   - Higher-order functions
   - Recursion basics

5. **Modular Programming**
   - Code organization
   - Function libraries
   - Import mechanisms
   - Best practices

## Key Concepts

### Function Benefits
- **Code Reusability**: Write once, use multiple times
- **Organization**: Break complex problems into manageable pieces
- **Maintainability**: Easier to update and debug
- **Testing**: Isolated functionality is easier to test
- **Collaboration**: Teams can work on different functions

### Best Practices
- Use descriptive function names
- Write clear docstrings
- Keep functions focused on single tasks
- Use appropriate parameter names
- Handle edge cases and errors
- Return consistent data types
