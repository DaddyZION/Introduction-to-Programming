## 📝 Exercise Instructions

1. **Read the Problem Statement**: Each exercise includes a detailed description of what you need to implement.

2. **Study the Examples**: Refer to the corresponding example files for guidance and inspiration.

3. **Start with Pseudocode**: Plan your solution before writing code.

4. **Test Thoroughly**: Create test cases to verify your implementation works correctly.

5. **Optimize**: Consider performance and memory efficiency for advanced exercises.

6. **Document**: Add comments explaining your approach and key algorithms.

1. Choose an exercise that matches your current skill level
