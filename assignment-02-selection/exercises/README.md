## 🔧 Quick Reference

### Basic Syntax Reminder:
```python
# Basic if
if condition:
    # do something

# if-else
if condition:
    # do something
else:
    # do something else

# elif chain
if condition1:
    # option 1
elif condition2:
    # option 2
else:
    # default option

# Boolean logic
if condition1 and condition2:
    # both must be true

if condition1 or condition2:
    # at least one must be true

if not condition:
    # condition must be false
```

*Remember: Programming is learned by doing. Practice these patterns until they become second nature!*
