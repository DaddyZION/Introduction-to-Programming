# Assignment 3: Iteration Constructs - Practice Exercises

Welcome to the practice exercises for Assignment 3! These exercises will help you master iteration concepts through hands-on coding practice.

## 📚 What You'll Practice

These exercises cover all the iteration concepts from Assignment 3:
- **For loops** with sequences and ranges
- **While loops** with conditions and validation
- **Nested loops** for 2D data processing
- **Loop control** statements (break, continue, pass)
- **Common loop patterns** (accumulator, find, filter, etc.)

## 🎯 Exercise Structure

Each exercise includes:
1. **Problem Description** - What you need to solve
2. **Learning Objectives** - What concepts you'll practice
3. **Starter Code** - Template to get you started
4. **Example Output** - What your program should produce
5. **Solution** - Complete working solution with explanations

## 📁 Files in This Directory

- `exercise-01-basic-loops.py` - Basic for and while loop practice
- `exercise-02-loop-patterns.py` - Common algorithmic patterns
- `exercise-03-nested-loops.py` - Working with 2D data structures
- `exercise-04-menu-systems.py` - Interactive programs with validation
- `exercise-05-comprehensive.py` - Complex problems combining all concepts

## 🚀 How to Use These Exercises

1. **Start with Exercise 1** and work through them in order
2. **Read the problem carefully** and understand what's required
3. **Try to solve it yourself first** before looking at the solution
4. **Run your code** and test with different inputs
5. **Compare with the provided solution** and understand the differences
6. **Experiment** by modifying the code to see how it behaves

## 💡 Learning Tips

- **Type out the code** - don't just copy and paste
- **Add print statements** to trace through loop execution
- **Test edge cases** - what happens with empty lists, zero values, etc.
- **Modify the exercises** - change requirements to explore variations
- **Time yourself** - see how quickly you can solve similar problems
