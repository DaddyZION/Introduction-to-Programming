## 📖 What are Sequence Constructs?

Sequence constructs are the foundation of programming - they represent statements that execute **one after another** in the order they appear. Think of it like following a recipe step by step.

### Key Concepts:

1. **Variables** - Named storage locations for data
2. **Assignment** - Storing values in variables
3. **Input** - Getting data from the user
4. **Output** - Displaying data to the user
5. **Expressions** - Calculations and operations

## 💡 Key Programming Concepts

### Variables
Think of variables as **labeled boxes** that store information:
```python
age = 25        # Integer (whole number)
name = "Alice"  # String (text)
height = 5.6    # Float (decimal number)
is_student = True  # Boolean (True/False)
```

### Sequential Execution
Programs execute line by line from top to bottom:
```python
print("Step 1")  # This runs first
print("Step 2")  # This runs second
print("Step 3")  # This runs third
```

### Input/Output
- **Input**: Getting information FROM the user
- **Output**: Showing information TO the user

## ⚠️ Common Mistakes to Avoid

1. **Variable naming**: Use descriptive names (`student_age` not `x`)
2. **Data types**: Remember that input() returns strings
3. **Order matters**: Statements execute in sequence
4. **Initialization**: Use variables only after assigning values
