# Assignment 3 Solutions – Iteration Constructs

This directory contains complete reference programs for the five iteration exercises. Each script demonstrates idiomatic loop usage, defensive programming, and helpful console output.

| File | Exercise | Key Concepts |
| --- | --- | --- |
| `exercise-01-basic-loops.py` | Basic loops | Counting, aggregation, sentinel-controlled while loops. |
| `exercise-02-loop-patterns.py` | Loop patterns | Accumulator, search, filter, map, and reduce style examples. |
| `exercise-03-nested-loops.py` | Nested loops | 2D data processing, table generation, pattern printing. |
| `exercise-04-menu-systems.py` | Menu systems | Interactive menus, validation, loop control. |
| `exercise-05-comprehensive.py` | Comprehensive system | Classroom analytics suite combining all loop strategies. |

Run any file with Python to explore the behaviour. Feel free to adapt the logic to create your own variations.
