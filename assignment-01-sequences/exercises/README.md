# Assignment 1: Sequence Constructs - Practice Exercises

## 🎯 Practice Problems

These exercises will help you master the concepts from Assignment 1. Start with the easier problems and work your way up to more challenging ones.

### Exercise 1: Personal Information Calculator ⭐
**Difficulty: Beginner**

Create a program that:
1. Asks the user for their name, age, and birth year
2. Calculates and displays their age next year
3. Calculates how many years until they turn 65
4. Displays a nicely formatted summary

**Expected Output:**
```
Enter your name: Alice
Enter your age: 22
Enter your birth year: 2001

=== PERSONAL INFORMATION SUMMARY ===
Name: Alice
Current Age: 22
Birth Year: 2001
Age Next Year: 23
Years Until Retirement (65): 43
```

### Exercise 2: Simple Calculator ⭐⭐
**Difficulty: Intermediate**

Create a calculator that:
1. Gets two numbers from the user
2. Performs all basic operations (+, -, *, /, //, %, **)
3. Displays the results in a neat format
4. Handles division by zero gracefully

### Exercise 3: Student Grade Processor ⭐⭐⭐
**Difficulty: Advanced**

Create a program that:
1. Collects information for 3 students (name and 4 test scores each)
2. Calculates each student's average
3. Determines the highest and lowest score overall
4. Creates a formatted report showing all data

### Exercise 4: Rectangle Properties Calculator ⭐
**Difficulty: Beginner**

Write a program that:
1. Gets length and width of a rectangle
2. Calculates area, perimeter, and diagonal length
3. Displays results with proper units and formatting

### Exercise 5: Temperature Converter ⭐⭐
**Difficulty: Intermediate**

Create a comprehensive temperature converter that:
1. Converts Celsius to Fahrenheit and Kelvin
2. Converts Fahrenheit to Celsius and Kelvin  
3. Converts Kelvin to Celsius and Fahrenheit
4. Displays all conversions in a table format

## 💡 Hints

1. **Use meaningful variable names** - `student_name` not `x`
2. **Format numbers nicely** - Use `:.2f` for 2 decimal places
3. **Add spacing** - Empty print() statements make output readable
4. **Test with different values** - Try edge cases like 0, negative numbers
5. **Comment your code** - Explain what each section does

## 🎓 Learning Goals

By completing these exercises, you should be comfortable with:
- Creating and using variables of different types
- Getting input from users and converting data types
- Performing mathematical calculations
- Formatting output professionally
- Writing programs that execute sequentially
- Debugging simple syntax errors

## 📝 Submission Tips

When you complete an exercise:
1. Test it with multiple different inputs
2. Make sure your output is neat and professional
3. Add comments explaining your logic
4. Check for spelling and formatting errors
5. Ensure your program doesn't crash with unexpected input
