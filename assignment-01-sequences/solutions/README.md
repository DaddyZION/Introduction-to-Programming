# Assignment 1 Solutions – Sequence Constructs

This directory contains reference implementations for the practice exercises in Assignment 1. Each script is fully runnable from the command line and includes inline comments plus helper functions to keep the logic organised.

## Included Solutions

| File | Exercise | Summary |
| --- | --- | --- |
| `exercise-01-personal-information.py` | Personal Information Calculator | Collects personal details and produces a formatted retirement summary. |
| `exercise-02-simple-calculator.py` | Simple Calculator | Performs all core arithmetic operations with input validation and graceful error handling. |
| `exercise-03-student-grade-processor.py` | Student Grade Processor | Gathers data for three students, computes statistics, and prints a detailed report. |
| `exercise-04-rectangle-properties.py` | Rectangle Properties Calculator | Calculates area, perimeter, and diagonal length with neat formatting. |
| `exercise-05-temperature-converter.py` | Temperature Converter | Converts between Celsius, Fahrenheit, and Kelvin and renders a comparison table. |

## How to Run a Solution

Each script exposes a `main()` function. Run the program you want to explore using Python:

```bash
python exercise-01-personal-information.py
```

Most programs contain a `demo()` helper so you can preview behaviour without typing manual input. Feel free to adapt the code for your own practice solutions.
