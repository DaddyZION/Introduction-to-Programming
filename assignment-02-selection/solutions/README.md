# Assignment 2 Solutions – Selection Constructs

Reference implementations for the decision-making exercises. Each script demonstrates clean branching logic, validation, and formatted output to mirror the scenarios described in the exercise brief.

| File | Exercise | Highlights |
| --- | --- | --- |
| `exercise-01-basic-conditions.py` | Basic conditions | Weather advice, grade classification, and age grouping using simple if/elif logic. |
| `exercise-02-boolean-logic.py` | Boolean logic | Login checks, discount eligibility, and event filters built with compound boolean expressions. |
| `exercise-03-nested-decisions.py` | Nested decisions | Admission, insurance, and game stat calculators showcasing multi-level branching. |
| `exercise-04-validation-systems.py` | Validation systems | Form validation utilities with contextual error messages. |
| `exercise-05-comprehensive.py` | Comprehensive scenario | Small business assistant tying together customer management, billing, and decision support rules. |

Run any solution with Python, e.g.:

```bash
python exercise-02-boolean-logic.py
```

Each script includes a `demo()` helper so you can preview the logic quickly before experimenting with your own inputs.
